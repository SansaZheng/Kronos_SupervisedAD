## About
A HI-Small sample from a [IBM AML Dataset](https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml?select=HI-Small_Patterns.txt)

Generated using IBM's [AMLSim](https://github.com/IBM/AMLSim)

## Description
Sample group HI has a relatively higher illicit ratio (more laundering).

The small sample features approximately **5 million transactions** across **518,573 accounts**.

1. HI-Small_Trans.csv - Accounts
2. HI-Small_Trans.csv - Transactions
3. HI-Small_Patterns.txt - Laundering Pattern Transactions
